转义字符：< 小于号，> 大于号，& 与号，" 双引号，© 版权符号； 使用实体可以保留多个空格：左边   右边。

标签说明：img、meta、link、br、hr 和 input 等是单标签；div、span、p、a 和 form 等是双标签。

外部样式表

<link href="style.css" rel="stylesheet">

本页主要采用这种方式，HTML 与 CSS 分开保存，便于维护。

内部样式表

<style> ... </style>

写在 head 中，只对当前页面生效。

内联样式

style="..."

直接写在元素上，优先级较高，但不适合大量使用。

在现有元素上使用 CSS 选择器

选择器找到 HTML 元素，声明块为它们设置具体样式。

input { font: inherit; }

标签选择器

页面中的 input 元素共享基础字体设置。

#selector-title { color: ...; }

ID 选择器

id 在页面中应保持唯一，选择时使用 #。

唯一元素
.selector-field { ... }

类选择器

同一个类可以用在多个元素上，选择时使用 .。

账号标签 密码标签
.selector-demo strong { ... }

组合与后代选择器

逗号让多个选择器共用样式，空格选择某个元素内部的后代。

    return "你好，" + name
}

    callback("这个是回调参数")
}

runCallback(param => {
    console.info(param)
})
